- `M2 竞品表现 → M2 净化`
- `M3 引用来源 → M3 净化`

## Convergence

`汇聚.并行收口 → M1 数据总览 → M1 净化 → M6 下一步行动 → M6 净化 → M10 最终摘要 → M10 净化 → 汇总.数据合并 → 结束`

## Routing guide

- Competitor report mismatch: M2 branch, but first verify incoming analysis records.
- Citation/media coverage: M3 branch, but missing answer-level sources usually originate in `geo-analysis.yml`.
- Brand language/expression: M4.
- Growth/opportunity recommendations: M5.
- Totals, rates, denominators: M1.
- Recommendations: M6.
- Executive summary: M10.
- Missing whole sections or wrong data types: parallel convergence and final merge.

## Boundary

This workflow summarizes existing analysis. It should not recreate missing competitor or reference records. Diagnose upstream first when source arrays are already incomplete.
